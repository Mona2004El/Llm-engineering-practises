Core LLM Engineering — Learning Journey

📌 About This Repository

This repository documents my learning journey through the Core LLM Engineering course by Ed Donner.

It contains my practice code, experiments, and notes as I learn how to build applications powered by Large Language Models (LLMs).

My goal is to develop practical skills in LLM Engineering and gradually progress toward building AI agents and Agentic AI applications.

🎯 Learning Objectives

- Understand Large Language Models (LLMs) and how they work.
- Learn how to interact with LLM APIs.
- Practice prompt engineering and tokenization.
- Build practical LLM-powered applications.
- Explore context windows, model capabilities, and API usage.
- Develop a foundation for RAG systems and AI agents.
